Before you start

  1. A real phone (not a desktop emulator — that's what missed these bugs).
  2. Open serfbound.com (or a LAN npm run build:web URL).
  3. Import your local SPAU.PA once — the map builder and community maps are import-gated like play.
  4. Keep this deck open in a second tab; switch back to record each verdict.

Mark every check Pass, Fail, or Skip. A phase closes only when all its checks pass; any Fail loops it (the Phase-34 pattern).

Most checks have a ▶ Open rig button: it boots the game straight into that check's exact state, with an in-game Pass/Fail panel that records right here. Tap it, do the one thing it asks, mark the verdict.
